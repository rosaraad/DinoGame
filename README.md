## 🎮 Features

* Main menu with Play and Quit options
* Dino running, jumping, and ducking animations
* Jump sound effects and background music
* Moving ground
* Cactus obstacles
* Flying bird obstacle
* Collision detection
* Game Over screen
* Restart button
* Score system

## 🛠️ Built With

* Python
* Pygame

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/DinoGame.git
```

2. Install Pygame:

```bash
pip install pygame
```

3. Run the game:

```bash
python main.py
```

## 🎮 Controls

| Key          | Action |
| ------------ | ------ |
| `Space`      | Jump   |
| `↓` Key Down | Duck   |
